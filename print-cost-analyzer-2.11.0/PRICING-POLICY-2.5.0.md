# Kebijakan Harga Print Cost Analyzer 2.5.0

## HVS A4/F4/A4s — 1 sisi

| Kelas | Reguler | Mulai tarif volume | Tarif volume |
|---|---:|---:|---:|
| BW | Rp300/sisi | sisi BW ke-250 | Rp250/sisi |
| Sebagian warna | Rp500/sisi | sisi ke-50 | Rp400/sisi |
| Full warna | Rp1.000/sisi | sisi ke-25 | Rp800/sisi |
| Pekat | Rp1.500/sisi | — | tidak otomatis |

Tarif volume bersifat progresif per kelas warna. Jumlah BW, Sebagian, dan Full dihitung terpisah di dalam pekerjaan yang sama.

## HVS A4/F4/A4s — 2 sisi

Tarif 2 sisi bersifat flat per lembar sejak lembar pertama dan tidak memiliki ambang volume tambahan.

| Pasangan sisi | Harga/lembar |
|---|---:|
| BW + BW | Rp400 |
| BW + Sebagian | Rp600 |
| Sebagian + Sebagian | Rp800 |
| BW + Full | Rp1.000 |
| Sebagian + Full | Rp1.200 |
| Full + Full | Rp1.500 |
| BW + Pekat | Rp1.800 |
| Sebagian + Pekat | Rp2.000 |
| Full + Pekat | Rp2.400 |
| Pekat + Pekat | Rp2.500 |

## Kelompok media 2.5.0

Media yang memiliki karakter dan harga hampir sama disederhanakan menjadi satu pilihan publik:

- HVS Putih 70–80 gsm: A4, F4, A4s, A3.
- Kertas Foto Glossy 210–230 gsm: A4, A3.
- Stiker Glossy 120–145 gsm: A4, A3+.
- BC / Buffalo / Manila tetap satu kelompok.

Media lain tetap dipisah jika perbedaan bahan/biaya cukup besar untuk memengaruhi harga.
