# Kebijakan Harga 2.4.0

## 1 sisi

Jumlah sisi dihitung terpisah untuk BW, Sebagian warna, Full warna, dan Pekat. Tarif volume hanya berlaku pada kelas yang memenuhi ambangnya dan diterapkan progresif mulai sisi pada ambang tersebut.

Untuk HVS A4/F4/A4s standar:

| Kelas | Reguler | Ambang | Tarif setelah ambang |
|---|---:|---:|---:|
| BW | Rp300/sisi | 250 sisi BW | Rp250/sisi |
| Sebagian warna | Rp500/sisi | 50 sisi | Rp400/sisi |
| Full warna | Rp1.000/sisi | 25 sisi | Rp800/sisi |
| Pekat | Rp1.500/sisi | — | tetap |

## 2 sisi

Tidak ada ambang harga volume. Setiap lembar dinilai sebagai pasangan sisi dan memakai tarif tetap sejak lembar pertama.

Untuk HVS A4/F4/A4s standar:

| Pasangan | Harga/lembar |
|---|---:|
| BW + BW | Rp400 |
| BW + Sebagian | Rp600 |
| Sebagian + Sebagian | Rp800 |
| BW + Full | Rp1.000 |
| Sebagian + Full | Rp1.200 |
| Full + Full | Rp1.500 |
| BW + Pekat | Rp1.800 |
| Sebagian + Pekat | Rp2.000 |
| Full + Pekat | Rp2.400 |
| Pekat + Pekat | Rp2.500 |

Media dan ukuran lain mengikuti `data/pricing-config.json`.
